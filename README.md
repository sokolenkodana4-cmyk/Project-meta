# Project meta

## Опис

Веб-сайт про історію видатних людей світу технологій та ігрової індустрії. Проект розповідає про знакових постатей, які вплинули на розвиток цифрових технологій, зокрема про Гейба Ньюелла (Gabe Newell) та інших піонерів індустрії.

## Можливості

- 📖 Інформативні статті про видатних людей
- 🎮 Розповіді про історію розробки видеоігор
- 📱 Адаптивний дизайн для мобільних пристроїв
- 🔗 Швидка навігація по сторінці
- 📤 Можливість поділитися сторінкою

## Технологічний стек

- HTML5
- CSS3 (з адаптивним дизайном для екранів менше 600px)
- JavaScript
- Адаптивна верстка (Responsive Design)

## Файли проекту

- `index.html` - основна сторінка
- `style.css` - стилізація та медіа-запити
- `script.js` - функціональність (поділ сторінки)
- `README.md` - документація
